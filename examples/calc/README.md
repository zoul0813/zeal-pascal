# Calculator

Type an expression, get an answer, or see where it went wrong. This is a small
recursive-descent interpreter written in Pascal.

## Run

Copy this entire folder to Zeal, then in ZShell use `cd T:/examples/calc` and
`./calc.bin` (or `cd H:/calc` when HostFS points at the examples tree). The
standalone binary needs no IDE library. To rebuild, start the IDE from this
folder, open `calc.pas`, and compile in Memory mode or saved Com-file mode.
The saved `calc.COM` has the same native executable format as `calc.bin`.

## Try it

Type `demo.in`: precedence makes `1 + 2 * 3` equal 7; parentheses change it to 9.
`-(4 - 10) / 4` produces 1.5, and `ans * 2` reuses that answer to produce 3.
`2 * (3 + )` reports a missing operand; `10 / (5 - 5)` reports division by zero.
A following `ans` still returns 3: failed expressions never replace the answer.
A blank line or Ctrl-Z quits. Names ignore case. ANS starts at zero.

The grammar accepts decimal numbers, `+ - * /`, parentheses, unary signs and
ANS. Multiplication/division bind before addition/subtraction; operators of
equal precedence associate left to right. There are no assignments, functions
or exponent literals. Input is limited to 72 characters. Errors echo the
expression with two leading spaces and a caret under the offending position;
division errors point at `/`. The caret is generated by the example itself,
independently of the IDE's original compiler/runtime error-location feature.

## Pascal features on show

- Mutually recursive `expression`, `term` and `factor`, with a forward declaration.
- `{$A-}` preserves each call's local operands while nested calls evaluate.
- A scanner position and error record shared across routine scopes.
- Real arithmetic, Val, Str and short-string editing.
- An explicit depth bound: at most eight simultaneous factor calls, including
  unary signs. Seven parentheses around a number fit; eight are refused.

Literal and intermediate magnitudes are capped at 1000000000. Divisors smaller
than 0.000000001 in magnitude are refused, including zero. The bounds keep the
native Real operations within their supported range instead of deliberately
triggering a runtime overflow. Results display up to six decimal places with
trailing zeroes removed; nonzero magnitudes below 0.000001 use the runtime's
scientific format. Real6 has finite precision: this is floating-point arithmetic.

`errors.in` exercises trailing input, malformed numbers, unknown names, tiny
and zero divisors, magnitude limits, unary depth and parentheses at both sides
of the depth boundary. A valid expression after errors demonstrates recovery.
All source, both input transcripts and the rebuilt standalone binary live here.
No files are written. These are native Zeal executables, not CP/M binaries.
